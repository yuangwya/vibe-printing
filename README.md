# Vibe Printing

Turn ideas into printable objects with CadQuery.

vibe-printing is a lightweight workspace for experimenting with parametric 3D
models, including designs created and refined with a coding assistant. Describe
an object, express its dimensions in code, and iterate toward a physical print.
Each model lives in its own directory with a small Python source file and
regenerable STEP and STL exports.

The project starts small: one example model, one build command, and basic
geometry validation. All dimensions use millimeters (mm).

## What is included

- **Parametric models:** adjust dimensions through constants at the top of each model file.
- **Automatic discovery:** add a `models/<name>/model.py` file without registering it elsewhere.
- **Geometry validation:** check for a valid single solid with positive volume.
- **STEP and STL exports:** continue editing in CAD software or import into a slicer.
- **Live preview:** inspect a model in a browser or VS Code and rebuild it on save.
- **Assistant guidelines:** `AGENTS.md` keeps future modeling work consistent.

## Quick start

Use Python 3.11 or later; Python 3.12 is recommended. From the repository root:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt

# Build and validate every model.
python scripts/build.py

# Validate or build a specific model.
python scripts/validate.py phone-stand
python scripts/build.py phone-stand
```

On Windows Command Prompt, activate the environment with `.venv\Scripts\activate.bat`.
In PowerShell, use `.venv\Scripts\Activate.ps1`.

For installation troubleshooting, see the [CadQuery installation guide](https://cadquery.readthedocs.io/en/latest/installation.html).

## Example: phone stand

The included model supports a centered phone in portrait or landscape:

- A 90 × 100 × 4.5 mm base and one central triangular rear brace support a backrest tilted
  65 degrees above the desk (25 degrees back from vertical).
- A 70 mm wide, 4 mm thick backrest and sloped seat support the phone, while an 8 mm front
  lip prevents its bottom edge from sliding forward. The seat and lip form one
  continuous profile, with the front wall extending down into the base.
- The seat provides 16 mm of clearance perpendicular to the backrest. The
  design was checked against centered rectangular phone envelopes from
  130 × 60 × 8 mm to 190 × 90 × 14 mm, including the case, in both orientations.
- The backrest, front lip's upper rim, and brace have 1 mm edge fillets. The base
  has rounded corners and a rounded upper rim.
- A pointed backrest window and two rounded base windows reduce material while
  retaining the side rails, perimeter, and central spine beneath the rear brace.
  The pointed window roof avoids a long horizontal bridge.
- Raised **Made by WYA** lettering sits on the front of the base, extending
  0.6 mm beyond its face. Overall dimensions are approximately
  90 × 100.6 × 84.2 mm.

This simplified version uses a thinner frame base, a shorter open backrest, and
a single rear brace. CAD solid volume is approximately 60.1 cm³, compared with
162.5 cm³ for the previous version.

A local Bambu Studio 02.08.02.61 comparison used the bundled X2D 0.4 mm nozzle
profile, its default 0.20 mm Standard process, Bambu PLA Basic, Textured PEI Plate,
two walls, 15% infill, and supports disabled. Both models were sliced upright
with the same settings:

| Estimate | Previous version | Simplified frame |
| --- | ---: | ---: |
| Filament | 76.10 g | 38.96 g |
| Total time, including preparation | 1 h 35 min 41 s | 1 h 10 min 15 s |

Estimated material use is 51.2% of the previous version; estimated total time
is 73.4%. Material cost at the same price per kilogram is therefore close to
half, but total cost including electricity, equipment, and labor is not proven
to be half. Material cost equals `38.96 / 1000 * price_per_kg` for this preset.
These are slicer estimates, not measurements from a physical print. The CLI
completed both slices but logged `Invalid T command` warnings for `T65279` and
`T65535` in the bundled start/end sequence. The generated G-code is used only
for this comparison; re-slice the STL in your normal printer project before
printing. Details are recorded in `models/phone-stand/print-estimate.json`.

The envelope checks verify geometric clearance and that the gravity projection
of a uniform, centered phone falls inside the base footprint on a level desk.
They do not cover uneven weight distribution, off-center placement, tapping,
cable pulls, surface friction, or material strength. Test the stand with your
own phone and case; add non-slip pads under the base if needed. Check the
sliced preview for any required support, especially under the front lip.

Edit the dimensions, backrest angle, clearance, edge radius, or label settings
in `models/phone-stand/model.py`, then rebuild:

```bash
python scripts/build.py phone-stand
```

The command writes:

- `models/phone-stand/exports/model.step` for further CAD editing.
- `models/phone-stand/exports/model.stl` for slicing and printing.

Import the STL into your slicer, such as Bambu Studio, using millimeters.
Confirm the model's orientation and dimensions before slicing.

## Live preview

Install the optional preview tools in the same virtual environment:

```bash
source .venv/bin/activate
python -m pip install -r requirements-preview.txt
python scripts/preview.py phone-stand --watch
```

The command starts a local [OCP Viewer](https://bernhard-42.github.io/ocp_viewer_docs/viewers/ocp_viewer/installation/)
at `http://127.0.0.1:3939` and opens it in your browser. Rotate, zoom, and inspect
the model there. Save changes to `models/phone-stand/model.py` to rebuild the
preview automatically. Rebuilding may take a few seconds, depending on model
complexity. Syntax errors and invalid geometry are reported in the terminal;
the last valid preview stays visible until the next successful build.

The watcher monitors only the selected `model.py`. Restart it after editing
other imported Python files. Previewing does not write STEP or STL files;
use `build.py` when you want updated exports. Press Ctrl+C to stop watching and
close the local viewer server.

```bash
# Preview once, keeping the browser viewer open until Ctrl+C.
python scripts/preview.py phone-stand

# Choose a different port if 3939 is already in use.
python scripts/preview.py phone-stand --watch --port 3940

# Print the viewer URL without opening a browser automatically.
python scripts/preview.py phone-stand --watch --no-browser
```

### Preview inside VS Code

Install the **Python** and **OCP CAD Viewer** extensions recommended by this
workspace. Select the project's `.venv` Python interpreter and start a viewer
from the OCP CAD Viewer sidebar's **Viewer Manager**. Then run:

```bash
python scripts/preview.py phone-stand --watch --vscode
```

Use `--port <number>` if the extension's viewer uses a different port. This mode
connects to the existing viewer and leaves it running when the script stops.
Model files need no preview imports or changes to their `build_model()` interface.
See the [extension documentation](https://github.com/bernhard-42/vscode-ocp-cad-viewer)
for viewer setup.

## Add a model

Create `models/<name>/model.py` using lowercase names with hyphens. Put dimensions
at the top and provide a `build_model()` function with no required arguments:

```python
import cadquery as cq

WIDTH = 20.0
DEPTH = 20.0
HEIGHT = 10.0


def build_model() -> cq.Workplane:
    return cq.Workplane("XY").box(
        WIDTH, DEPTH, HEIGHT, centered=(True, True, False)
    )
```

Return one connected solid, with its bottom at Z=0 and the XY plane as its print
base. Importing the file should not build or export a model or open a window.
The build script creates the model's `exports/` directory when needed.

`build.py` and `validate.py` accept multiple model names and process all models when none are
specified. They also work from another directory when invoked by absolute path.

## Validation scope

`validate.py` checks the return type, shape validity, solid count, and positive
volume, then reports bounding-box dimensions and volume. `build.py` performs
these checks before exporting.

These checks cover the CAD geometry generated from source. They do not verify
STL mesh quality, minimum wall thickness, supports, fit tolerances, or load
capacity. Review the sliced preview and validate the design with a test print.
