# Label font

`VibePrintingLabels-Bold.otf` is a renamed, glyph-subset derivative of
Noto Sans CJK SC Bold, licensed under the SIL Open Font License 1.1.
It contains only the characters used by the phone-stand-2 labels.
Copyright notices and the full license are in `OFL.txt`.

Upstream font: https://github.com/notofonts/noto-cjk/blob/main/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Bold.otf

Subsetting and renaming were performed with fontTools. Rebuild the subset
from the upstream font if a model needs additional characters.
